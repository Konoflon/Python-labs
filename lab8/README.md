# Отчёт

## Финансовый трекер расходов

### 1. Описание

Приложение предназначено для учета личных финансов в формате консольного интерфейса. Позволяет добавлять расходы по категориям, просматривать историю операций и общую сумму трат.

### 2. Инструкции по запуску
#### Требования
- Установленный `Python 3.6` или выше.
- Права на запись в папку с программой (для сохранения файла данных).
#### Запуск
Запустите приложение командой:
``` bash
python 3 main.py
```

### 3. Краткая справка

После запуска вы увидите меню. Используйте цифры для выбора действия:

| Команда | Действие |
|---------|----------|
| **1** | Добавить расход (введите сумму, категорию и описание) |
| **2** | Показать все (отобразить таблицу всех расходов и итог) |
| **3** | Удалить запись (выберите номер строки для удаления) |
| **4** | Выход (завершить работу программы) |

### 4. Хранение данных
Все записи сохраняются в файл `expenses.json` в формате JSON. Вы можете открыть его любым текстовым редактором, но рекомендуется редактировать данные только через меню программы.
